# 当前日志页面调整 V0.2.3

依据用户提供的当前日志原型图片重建内容区域，沿用系统现有顶部导航和侧边菜单。

## 页面结构

- 顶部：集中式运维、场站、日期、班次、班后交代、值班记事。
- 值班信息：场站、日期、班次、值班负责人、值班人员、班次时间。跨日结束时间标注“次日”。
- 班前交代：上一班已提交的班后交代，保留换行。上一班未填写时明确提示待补。
- 值班情况：类型、时间、内容、操作；内部滚动，倒序显示；查看详情进入对应业务记录，值班记事在原页弹窗查看。
- 缺陷记录：状态、缺陷单号、发现人、缺陷等级、设备名称、发现时间、审核提交时间。点击单号查看缺陷。

## 数据及交互规则

按场站和班次实际起止区间汇总，起点包含、终点不包含，跨日不拆断。汇总值班记事、调度命令、缺陷、工作票、操作票、通知交代；同一业务记录只显示一次新增事件，审批等状态变化不重复计为新增。缺陷表显示本班新增缺陷。

使用数据库现有日期、人员和设备，不硬编码图片中样例值，不重置已有业务数据。未配置成员显示“未配置”，历史记录未提供发现人显示“—”。未单独登记发现时间、审核提交时间时，使用登记提交时间。

值班记事仅当班可新增。班后交代在班中保存草稿，草稿不提前发布到下一班；班次结束后可提交或补填交代，保持到点自动交班的既有规则。
