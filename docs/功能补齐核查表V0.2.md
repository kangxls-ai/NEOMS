## 明确保留的演示简化

1. 正式票据为状态门槛控制的浏览器打印/另存PDF，含版本、人员、时间与过程字段；**尚未做真实纸票逐栏套打、后台直接生成PDF、电子签章**。
2. 操作票只有原型明确展示的集电线路“运行转检修”13项可恢复为原型演示模板，文字不全处已标记；其余转换项目仅为可编辑待补模板，不能宣称规程已完整。电气刀闸仍按基线保留待定。
3. 年度职责采用UTF-8 CSV，不直接导入xlsx；人员/延期/试运行保存结构化过程及批准信息，不增加确认基线之外的审批链。
4. 模拟时钟通过工具推进；没有生产实时定时器、SCADA接入、短信或库存系统。保留最近48次模拟测点，不替代历史时序数据库。
5. 其他业务域的完整流程未在原型中定义，保留切换入口和范围提示，不虚构能碳/户用储能业务功能。
