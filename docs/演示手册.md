# 领导演示手册（约20分钟）

## 准备

以 admin / Demo@2026 登录。右上角时钟可恢复演示数据，初始时刻2026-11-02 09:30。重置仅清理此项目演示业务记录，不删除数据库；已有上传文件保留，以避免误删。先介绍顶部导航、左侧菜单和身份切换，再展示工作台待办。

## 主线：逆变器异常闭环（10分钟）

1. “场站信息管理 → 设备监测”，设备卡展示模拟温度、功率与趋势。02号逆变器已有异常；模拟再次采样可观察异常次数聚合。采样按钮只操作演示数据库。
2. 工作台“待研判异常”或“运行管理 → 异常事件”，打开02号异常，选择“研判并登记缺陷”，填写连续温升和现场异响依据。关联单据中可查看新缺陷，此时尚未生成工单。
3. 切换调度周宁，在缺陷审批打开新缺陷，可先退回并补充重提，再审批通过，生成一张待派发消缺单。侧栏推荐班组/负责人有场站、技能和在办任务依据。确认派发，完成时间选当日18:00以后。
4. 切换现场李明，接单后尝试开工，将提示先关联许可票。进入“关联单据 → 编制关联工作票”，选择电气一种，点击“填入演示编制内容”，核对设备、负责人、措施和危险点，保存并提交签发。
5. 切换王磊签发，切换李明确认，再切换陈杰许可。每个阶段在侧栏有对应动作。未许可不能正式打印。需要展示退回时，在任一确认处退回，修改重提后从签发重新开始，原历史可查。
6. 许可后可以正式打印，浏览器选择“另存为PDF”。返回关联工单，切换李明开工。在“执行/处置”点击模拟处置填充，补充现场照片或添加标识清晰的模拟复测证据，再保存处置并提交验收。
7. 切换站长赵岚，待验收页面显示关联票据尚未终结，禁止验收通过。可展示退回处置；现场补充后再次提交。
8. 打开工作票，在执行页逐项登记措施，登记一次试运行/延期/人员变更过程。选择“终结补录”，填写现场恢复说明，上传附件，或添加“模拟终结记录”附件，再终结。
9. 回消缺工单，站长勾选已核验证据并填写结论，验收通过。工单已关闭、缺陷已消缺，历史保留各身份和时间。监测采样独立于验收；可再模拟正常温度展示恢复采样，不冒充真实设备告警复归。

## 扩展流程（每项1—2分钟）

- **票据阻断**：预置“散热检修待验收”关联 ticket-5 和 operation-1，两个均须终结。逐一查看比一键自动关闭更便于说明约束。
- **退回处置**：预置“逆变器恢复条件不足退回”，恢复温度80℃，有退回说明；将温度改为54℃、保存重提后验收。票据终结附件已有虚构样例。
- **巡检**：打开“本班场内巡检”，执行页按点查看。将未执行项填异常，先登记关联缺陷，再提交完成。原巡检完成，新缺陷独立审批消缺。
- **定检规则**：看箱变日常维护规则的设备、条件交集和未来触发预览。推进时钟至11月2日10:00，规则自动生成工单，负责人取当班李明。完成各项后由负责人完成，无独立验收。再次同刻触发不重复建单。
- **缺班补派**：将时钟推进至11月4日10:00（该日早班故意缺失），生成待分配任务并通知调度。补派后保留计划触发时间及规则快照。
- **跨日交接**：值班日历夜班20:00到次日08:00。推进到班次结束，自动交班；交代空缺标待补，下一班照常进行。补填后下一班的班前交代立即引用更新。
- **排班**：批量轮排选择未来11月8日至10日、按顺序选负责人，早/夜班可标次日。预览再保存。休假调班预览可看到后续负责人顺延，休假人员排最后。重叠班次会拒绝。
- **日志**：当前日志刷新事件，票据/工单/缺陷/命令/通知/记事按场站和真实班次区间落入日志，倒序查看并跳转。
- **工作票**：列表内四类样例分别展示不同措施分组；三类票双确认，联系单仅签发。草稿有水印，终结附件可打开。
- **操作票**：六种一级类型保留，下属转换项目为可编辑演示模板。签发后按顺序登记操作，再上传终结附件；不能跳过前项。引用操作票专用危险点库。
- **通知/命令**：新增通知在系统消息中心可见；调度命令“操作完成→待回令→回令完成→已结束”。
- **配置**：修改危险点库不改变已有票据快照；年度职责下载UTF-8 CSV模板，导入预览会反馈未匹配、重复和无效年份，确认时只写入有效行。固定流程只读。

## 演示提示

时间使用模拟业务时钟，选择计划/延期时间时须晚于该时钟。若时间已推进至11月4日，主线到期时间也相应调整。建议一条演示路线开始前重置，避免已有过程影响下一次。真实凭据不在演示资料中；预置人员、单位和设备均为虚构。
