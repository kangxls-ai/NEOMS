# 0.2.2 直接启动验证

推荐用法：进入发布目录，仅执行：

```sh
java -jar neoms.jar
```

保留发布目录中的lib和config。数据库连接在config/application-local.yml配置一次，升级时保留旧文件即可。无需loader.properties、-Dloader参数或-cp参数；前端仍在config/static，依赖仍在lib。

本次Windows Java21实际验证：

| 场景 | 结果 |
|---|---|
| 标准目录，java -jar neoms.jar，无JVM参数 | 健康检查、登录、MySQL连接、外置前端及附件均成功 |
| 安装目录含中文和空格，在该目录执行相同命令 | 启动成功 |
| 从其他工作目录用含空格的完整JAR路径启动 | 成功，config/static、logs和data仍定位在JAR旁 |
| 标准MANIFEST主类与Class-Path检查 | 通过，业务JAR约61KB，不含BOOT-INF内嵌依赖 |
| 业务回归 | 9项后端测试通过 |

Linux/macOS采用相同的标准JAR启动机制，本次没有在这两个操作系统实机运行。
